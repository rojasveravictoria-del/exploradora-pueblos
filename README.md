# Exploradora de Pueblos Originarios

Plataforma de estudio con fichas, quiz y juegos sobre los pueblos originarios de Chile (Atacameño, Aymara, Mapuche, Rapa Nui, Selk'nam y Kawésqar), para Ciencias Sociales de 2º básico.

Es un solo archivo `index.html`, sin instalación. Las estrellas se guardan en el navegador.
